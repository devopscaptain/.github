## 🚀 Featured Projects

### [SkyArch AI](#)
Open-source multi-cloud architecture diagramming tool — my flagship personal project.
- Full agent suite: diagram generator, architecture reviewer, cost estimator, IaC exporter
- Multi-cloud provider catalogs (AWS / GCP / Azure)
- Packaged as a complete Claude Project (agent definitions + skill files) for reuse

### Terraform Plan Visualizer
Turns raw `terraform plan` output into a readable, visual diff using custom SVG mascot characters —
built as an open-source, community-distributed tool.
- Containerized via Docker
- Distribution strategy centered on open-sourcing + Medium/community outreach

### AWS MGN/DMS → Terraform Automation
Auto-generates and imports Terraform configuration for AWS MGN (VM) and DMS (database) migrated
resources — enforcing account guardrails and org standards by default, eliminating manual
post-migration cleanup.

### Enterprise Ansible Automation (Air-Gapped Windows)
Role-based Ansible pipelines provisioning IBM WebSphere, ActiveMQ, Liberty, JBoss, WildFly, and SQL
Server in disconnected environments, following a consistent house pattern (`group_vars` as single edit
point, `vars_prompt` credentials, tagged tasks, size-based idempotency).

### GitHub Org SSO/SCIM Migration
Migrated a GitHub organization's SSO/SCIM configuration from one Okta tenant to another —
**175 users, 657 repos**, standard (non-EMU) org.

### [InstanceIQ — EC2 & RDS Advisor](https://github.com/devopscaptain/AWS-Instance-Explorer)
Static web app for exploring every AWS EC2/RDS instance type — workload guidance, side-by-side
comparison, and live on-demand pricing, with zero backend and zero AWS credentials required.
- Vanilla HTML/CSS/JS, no frameworks or build step
- Pricing data auto-refreshed weekly via a GitHub Actions workflow
- Dark/light themes, full-text search, accessible (ARIA roles, reduced-motion support)
